# CashPulse AWS 인프라 비용 최적화 분석 보고서

## 발견된 비용 문제 (리소스별 상세)

### EBS 볼륨 타입 최적화 미적용
- **대상 리소스**: 10개 EBS 볼륨 (각 200GB)
- **현재 상태**: 모든 볼륨이 gp2 타입으로 구성
- **문제점**: 최신 gp3 타입 대비 20% 높은 비용 구조
- **영향 범위**: 총 2,000GB 스토리지에 영향
- **월간 비용 낭비**: $40 (gp2 $200/월 vs gp3 $160/월)

### 리소스 사용률 현황
- CloudWatch 메트릭 분석 결과, 모든 EBS 볼륨이 활발히 사용 중
- IOPS 활동이 지속적으로 관찰되어 삭제 대상은 없음
- 볼륨 크기는 적절한 것으로 판단됨

## 근본 원인 분석

### 기술적 원인
1. **레거시 리소스 타입 사용**: 인프라 생성 시점에 gp2 사용
2. **마이그레이션 정책 부재**: gp3 전환 가이드라인 미수립
3. **정기 검토 프로세스 부재**: 비용 최적화를 위한 체계적 리소스 검토 없음

### 조직적 원인
- FinOps 관점에서의 리소스 라이프사이클 관리 체계 부족
- 신기술 도입 시 기존 리소스 업그레이드 정책 부재
- 비용 모니터링은 있으나 최적화 액션으로 연결되지 않는 구조

## 개선 방안 (우선순위 순)

### 1순위: EBS 볼륨 타입 전환 (즉시 실행 가능)
**대상 볼륨 (10개)**:
- ebs-volume-dsw4lu, ebs-volume-fx4sld, ebs-volume-0kb9hc
- ebs-volume-jzay9q, ebs-volume-5y3lvz, ebs-volume-jt1k57
- ebs-volume-wtj7n2, ebs-volume-p0rkuy, ebs-volume-yp7zay
- ebs-volume-10nvbc

**실행 방법**:
1. Terraform 코드에서 `type = "gp2"`를 `type = "gp3"`으로 변경
2. `terraform plan`으로 변경 사항 확인
3. `terraform apply`로 적용 (다운타임 없음)

**위험도**: 낮음 (AWS에서 지원하는 무중단 전환)

### 2순위: 정책 및 프로세스 개선
1. **기본 설정 변경**: 향후 모든 EBS 볼륨을 gp3로 생성
2. **정기 검토**: 분기별 비용 최적화 검토 프로세스 수립
3. **모니터링**: 신규 AWS 서비스/타입 도입 시 기존 리소스 업그레이드 계획 수립

|------|-----------|----------------|--------|----------|
| EBS gp2→gp3 전환 | $200 | $160 | $40 | $0.02/GB × 2,000GB |
| **총 절감액** | | | **$40** | |

### 세부 계산
- **gp2 비용**: $0.10/GB/월 × 200GB × 10볼륨 = $200/월
- **gp3 비용**: $0.08/GB/월 × 200GB × 10볼륨 = $160/월
- **월간 절감**: $200 - $160 = $40
- **연간 절감 예상**: $40 × 12 = $480

### 투자 대비 효과
- **구현 시간**: 1시간 미만
- **투자 비용**: $0 (기존 인프라 활용)
- **ROI**: 즉시 효과 발생
- **위험도**: 매우 낮음 (AWS 공식 지원)
