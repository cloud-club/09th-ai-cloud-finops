- 예측 가능한 일정한 트래픽이면 PROVISIONED 유지하되 적정 용량 설정

### 3순위: 태깅 전략 수립
- 모든 Kinesis 스트림에 Environment, Owner, Project 태그 추가
- 태깅 정책 문서화 및 신규 리소스 생성 시 필수 태그 검증 자동화

- Kinesis 메트릭 기반 사용률 모니터링 대시보드 구축
