### 권장값 산출 근거

```
권장 CPU = 현재 CPU(4096) x P99 사용률 x 1.2(버퍼) → Fargate 유효값으로 올림
         = 4096 x ~23% x 1.2 ≈ 1130~1197 → 2048 (Fargate 유효 CPU)

권장 Memory = 현재 Memory(8192) x P99 사용률 x 1.2(버퍼) → Fargate 유효값으로 올림
            = 8192 x ~38% x 1.2 ≈ 3565~3940 → 4096 (Fargate 유효 Memory)
```

## 적용 시 주의사항

1. **단계적 축소**: 한 번에 50% 축소는 권장 최대치입니다. 가능하면 4096/8192 → 2048/4096 단계로 적용하세요.
2. **모니터링**: 적용 후 최소 1주일간 CPU/Memory 사용률을 모니터링하세요.
3. **Auto Scaling**: Auto Scaling이 설정되어 있다면 min/max 값도 함께 검토하세요.
4. **medium 리스크 리소스**: s5gjp0, 75ze4y, otgk50는 메모리 스파이크 이력이 있어 보수적 접근을 권장합니다.
5. **용량 부족 리소스 우선**: fv7ul7, 0xveyz는 비용 절감보다 **스케일업이 시급**합니다.
